# Rune's Scroll

An arcane-night web app for the Meta Ray-Ban Display (600×600): Meta news, XR industry news, and a pop quiz about Meta and its products. Gold linework on pure black — the black renders see-through on the additive display. Built as a static page — no backend, no tracking.

Live at: https://runedaraven.github.io/runes-scroll

Built with Rune.
